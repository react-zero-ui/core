`geist-latin.woff2` is the Geist Latin font bundled with Next.js 15.5.18
(`next/dist/next-devtools/server/font/geist-latin.woff2`). It is used to exercise
`next/font/local` without network requests. Its SIL Open Font License is in
[OFL.txt](./OFL.txt); upstream: https://github.com/vercel/geist-font.
